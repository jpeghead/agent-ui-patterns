- [Field notes](field-notes.md): what these cost to learn, from the other side of the prompt.

A note on the word "agent". Here it means software that takes several steps toward a goal on your behalf, using tools, where you did not specify each step. A chat that answers is not an agent. A script that runs a fixed sequence is not an agent. The interface problems below appear exactly when the software decides what to do next and the person has to live with it.
